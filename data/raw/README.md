# Raw data inputs

Primary real-data input for the main pipeline:

- `real_proxy/repo_week_panel_q1_2025_expanded.csv`
- `real_proxy/repo_week_panel_q1_2025_expanded_metadata.json`
- `real_proxy/repo_week_panel_q1_2025_expanded_dictionary.csv`

This is a public GH Archive–derived repo-week panel with observed event counts and proxy AI-signal variables.

Legacy pilot-only files are retained for reference but are not used in the primary pipeline:
- `real_proxy/repo_week_panel_pilot.csv`
- `real_proxy/repo_week_panel_pilot_metadata.json`
- `real_proxy/repo_week_panel_pilot_dictionary.csv`
